## 2. Two loops (only one is running)

### 2.1 Automation loop (dominant today)

```text
Yahoo bars → indicators → ranking → Buy/Hold/Sell rules → ledger → email
```

2026-08-11 swing reality: plan 5 names → **0 fills** → mark_only / session_closed / switch_blocked → “thin learning.”

### 2.2 Judgment loop (mostly absent)

```text
Buy → Why? → What happened? → Was reasoning correct?
    → What evidence changed? → Should future reasoning change?
```

A **learning statement** (target):

> “I believed EICHERMOT would outperform because of sector momentum. After 20 sessions, sector RS weakened while earnings assumptions held. I now weight valuation over momentum for this regime.”

Emails almost never produce that. They produce **state** (watch, insufficient, pending).

**Learning event (BRE locked, restated):**  
`evidence + belief + comparison + updated belief` — not timers, packets, or emails alone.

## 4b. Cognitive Work Scheduler (CWS) — LOCKED amendment B

**Trap:** Atlas stays **event-driven** (timer → tick → hold → email) even with WSO shells.

**Required loop:**

```text
goal → what do I not know? → questions → plan research
    → collect evidence → revise beliefs → better questions
```

Curiosity / `unknowns[]` elevate from feature to **scheduler primitive**.

### Daily Cognitive Quota (thinking quota, not CPU)

Every IST day Atlas **must** attempt (even when market closed / no trades):

| Quota | Count | Example |
|-------|------:|---------|
| Belief reviews | 5 | Open-book WSO / thesis check |
| Research tasks | 3 | IRA / filings / FCF asks from unknowns |
| Contradiction checks | 2 | Thesis vs new evidence |
| Counterfactual | 1 | CF panel or “what if not held” |
| Long-term synthesis | 1 | “What did I understand better today?” |

OI: `OI-CWS0`. Worker drains quota under Cognitive Budget + Host Guard.

### Operator visibility

- **Hourly digests** IST **08:00–20:00**: activity + learnings + CWS progress (`OI-HOURLY0`)
- **Evening** still the deep judgment report
- **Market UI ledger tables** for all labs (`OI-LEDGER-UI0`)

## 4c. Daily Cognitive Agenda (DCA) — LOCKED amendment C

**Gap the review named correctly:** CWS quota alone can fill with structural stubs (`belief_review=5`) while Atlas still **does not pursue understanding**. Quota ≠ agenda.

**Required:** every IST morning Atlas publishes a **Daily Cognitive Agenda** — intentional thinking targets for the day — then CWS/J4 drains that agenda even when the market is closed.
